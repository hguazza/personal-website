# Resource Templates

Copy the relevant template, fill it in, and paste it here — I'll add it to `lib/resources.ts`.

Fields marked `// optional` can be omitted if you don't have the info.

---

## Paper

```
title:       "..."
description: "..."        ← one sentence on what the paper is about
solved:      "..."        ← what it helped you understand or solve
url:         "..."        // optional — link to arXiv, PDF, or abstract page
authors:     "..."        // optional — e.g. "Vaswani et al."
year:        0000         // optional — publication year
```

---

## GitHub Repo

```
title:       "owner/repo"  ← e.g. "langchain-ai/langchain"
description: "..."         ← one sentence on what the repo does
solved:      "..."         ← what it helped you understand or solve
url:         "https://github.com/..."
tags:        ["...", "..."] // optional — languages or frameworks, e.g. ["Python", "LangChain"]
```

---

## YouTube Video

```
title:       "..."
description: "..."         ← one sentence on what the video covers
solved:      "..."         ← what it helped you understand or solve
url:         "https://www.youtube.com/watch?v=..."   ← or youtu.be/... short link
channel:     "..."         ← channel or creator name, e.g. "Andrej Karpathy"
```

---

## Article

```
title:       "..."
description: "..."         ← one sentence on what the article is about
solved:      "..."         ← what it helped you understand or solve
url:         "..."         // optional — link to the article
source:      "..."         // optional — publication or author, e.g. "Anthropic Blog"
```
